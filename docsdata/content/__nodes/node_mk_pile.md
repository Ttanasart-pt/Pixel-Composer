Create piling of a surface. Like the <node Node_Scatter> but with fixed pattern.

## Properties

[proptable]
Object
Array Select|When inputing a surface array. Whether to render array in order or randomize the order.
Depth|Set artificial thickness to each surface.

Pile
Origin|Pile origin.
Amount|Amount of objects.
Angles of Repose|Angle where the pile is too steep causing the next object to fall down.
Column Shift|Distance where the next pile begin.
Center Bias|Gives extra height to the center.
Shuffle|Add randomization to where the next pile will be.

Offset
X Offset|Add random offset in X axis.
Y Offset|Add random offset in Y axis.

Scatter
Amount|Scatter extra object around the pile.
Range|Scatter range.
[/proptable]
