Hough transform is used to extract geometry information (line, circle) from a surface. Hough filter allow you to use hough transform artisticly.

## Properties

[proptable]
Hough
Shape|Hough shape
Radius|Hough circle radius
Intensity|Hough effect intensity
Max Range|Maximum filter scale relative to surface size.
Snap Angle|Snap line angle

Rendering
Thickness|Line thickness
Color|Render color
Line Fade|Fade line over distance
[/proptable]
