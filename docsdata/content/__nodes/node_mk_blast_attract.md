Attract blast particle toward one points.

## Properties

[proptable]
Blast
Blast|Blast object.
Mask|Filter object type to be affected.

Selection
Selection|Apply effect only to selected area.

Attract
Target|Attract target.
Overshoot|Allow particle to overshoot intead of stop when it reaches the target.

Spiral
Spiral|Apply perpendicular force to create spiral path.
[/proptable]
