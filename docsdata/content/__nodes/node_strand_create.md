Strand creator.

## Properties

[proptable]
Generation
Source|Strand source type.
Strands|Amount of strands.

Strand
Length|Strand segment length.
Segment|Amount of segments per strands.
Direction|Initial direction.
Elasticity|Length preservation, the higher the value the easier it is to stretch each segment.
Structure|The ability for the strand to keep its original shape.
Root Strength|The force required to break strand from its root. Set to -1 to make strand infinitely strong.
Restitution|Minimum speed before the strand stops moving completely.

Curl
Curl frequency|How frequent the hair will curl.
Curliness|Curl amplitude.
[/proptable]
