Import array of image path into surface array.

## Properties

[proptable]
Image
Path|Array of path to the images files.
Padding|Apply extra padding in each images.
Canvas Size|Define the surface size to use when importing images with different dimensions.\n
 - **Individual**: Each surface use their own dimension.\n
 - **Maximum**: All surfaces will use the largest dimension.\n
 - **Minimum**: All surfaces will use the smallest dimension.
Sizing Method|Method for adjusting surface size when select Maximum or Minimum mode.\n
 - **Padding/Crop**: Keep original image resolution and add empty pixel or crop the content to size.\n
 - **Scale**: Scale image to the new dimension.
[/proptable]
