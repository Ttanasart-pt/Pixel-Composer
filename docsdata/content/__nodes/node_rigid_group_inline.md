Parent group for RigidSim system.

## Properties

[proptable]
Gravity
Direction|Gravity direction
Strength|Gravity strength

Simulation
Simulation Scale|Scale factor from pixel to simulation unit.
Sleepable|Make static object stop receiving data.
Continuous|Simulate moving object smoothly. Can fix problem with fast moving small object.

Wall
Use Wall|Add solid wall around the domain.
Wall Friction|Control how fast object slide on wall.
[/proptable]
