Draw an isometric cube.

## Properties

[proptable]
Output
Dimension Type|Method for setting output dimension.
Padding|Add extra space in each direction.

Shape
Base|Size of the cube base.
Base Offset|Add offset in each side of the cube.
Base Expand|Expand dynamic dimension to fit the original base.
Base Rotation|Base angle.

Depth
Depth|Cube height.
Depth Offsets|Add depth offset to each corner.
Depth Ref.|Set dynamic dimension to use fix custom depth to prevent resizing.
[/proptable]
