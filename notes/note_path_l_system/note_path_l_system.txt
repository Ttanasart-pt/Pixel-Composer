# Lindenmayer System

Lindenmayer Systems (L-system) is a system of drawing line using simple string. The line is drawn from a pointer (sometime called a turtle). The pointer is controlled by a rule containing letters or symbols.

## Symbols

<table>
<tr> <td>**F**</td>  <td>Move forward and draw a line</td>                </tr>
<tr> <td>**G**</td>  <td>Move forward without drawing a line</td>         </tr>
<tr> <td>**+**</td>  <td>Rotate to the left</td>                          </tr>
<tr> <td>**-**</td>  <td>Rotate to the right</td>                         </tr>
<tr> <td>**\[**</td> <td>Save current state in a stack.</td>              </tr>
<tr> <td>**\]**</td> <td>Restore state from the top of the stack.</td>    </tr>
<tr> <td>**\***</td> <td>Rotate the secondary angle positively (3D).</td> </tr>
<tr> <td>**/**</td>  <td>Rotate the secondary angle negatively (3D).</td> </tr>
</table>

Move distance and turn angle are fixed.

## Rules Generation

Rules are generated by repeatedly replace a letter with another letter(s). For example.

<table>
<tr> <td>**X**       </td> <td> Starting rule </td>                                </tr>
<tr> <td>**X > FX**  </td> <td> Replace X by FX </td>                              </tr>
<tr> <td>**F > X+F** </td> <td> Replace F by X+F </td>                             </tr>
</table>

Applying these rules the first time we will get:

<table>
<tr> <td>**X**  </td> <td> Starting rule </td>                                     </tr>
<tr> <td>**FX** </td> <td> Apply the first rule replacing X with FX </td>          </tr>
</table>

The second iteration will be:

<table>
<tr> <td>**FX**     </td> <td> Result from the first iteration </td>               </tr>
<tr> <td>F **FX**   </td> <td> Applying the first rule replacing X with FX </td>   </tr>
<tr> <td>**X+F** FX </td> <td> Applying the second rule replacing F with X+F </td> </tr>
</table>

Notice that both rules are being applied at the same time, thus the seconds rule won't replace the letter replaced by the first rule. 
By repeating these operations many times we can construct more complex rule.

## Random Rules

You can also apply multiple rules to the same letter to randomize rule selection.

<table>
<tr> <td>**X > F+X** </td> <td> Replace X by F+X </td>                             </tr>
<tr> <td>**X > F-X** </td> <td> Replace X by F-X </td>                             </tr>
</table>

These rules caused every X to has 50% chance to become F+X and 50% chance to become F-X.
