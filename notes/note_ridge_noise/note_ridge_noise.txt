Generate ridge, eroded valley pattern either from random noise or provided heightmap.

## Properties

[proptable]
Noise
Heightmap|Optional heightmap. If not provided a random perlin noise will be used.
Mode|Ridge shape.
Cell Scale|Ridge scale.
Blending|Amount of blurring between cell.

Ridge
Ridge Scale|Ridge wave frequency.
Ridge Rotation|Offset ridge angle.
Ridge Contrast|Ridge wave amplitude.
Ridge Multiplier|Multiply ridge scale by birghtness.

Iteration
Iteration|Number of iteration.
Itr. Factor|Multiplier factor per iteration.
Blend Mode|Blend mode between each iteration.
[/proptable]
