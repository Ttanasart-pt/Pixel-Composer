MK Tree is a system for generating tree. A tree consists of 3 main components: <node Node_MK_Tree_Root>, <node Node_MK_Tree_Branch> and 
<node Node_MK_Tree_Leaf>. Lastly <node Node_MK_Tree_Render> is used to render a tree to surface.
