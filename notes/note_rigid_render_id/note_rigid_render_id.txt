Simulate and render each rigidbody object as a unique color.

## Properties

[proptable]
Simulation
Simulate|Simulate rigidbody before rendering.
Timestep|Simulation timestep (in milisec).
Quality|Amount of simulation substeps.

Rendering
Round Position|Round object position to decimal before drawing.
Normalize Output|Whether to output as normalized 8-bit surface on raw 16-bit float surface.
[/proptable]
