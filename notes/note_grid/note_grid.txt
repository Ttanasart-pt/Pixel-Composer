## Properties

[proptable]
Pattern
Position|Grid offset.
Angle|Rotation
Invert Size|Whether to define the amount of cell (invert on) or the size of each cell (invert off).
Grid Size|Grid size based on the <junc Invert Size> setting.

Gap|Thickness of the gap between each cell.
Uniform Gap|Use pixel position to calculate gap instead of grid distance field.

Diagonal|Rotate the grid by 45deg and scale the size by sqrt(2).
[/proptable]

[proptable]
Shift
Shift Axis|The axis to apply shift to.
Shift|Shift every even row by a fix amount to create brick pattern.
Random Shift|Shift each row randomly.
Secondary Shift|Additionaly shift every 2 rows.
[/proptable]

[proptable]
Scale
Random Scale|Apply random scale along the <junc Shift Axis>.
Secondary Scale|Apply custom scale every 2 rows.
[/proptable]

[proptable]
Render
Render Type|Rendering Modes
Tile Color|Gradient defining random tile color.
Gap Color|<junc Gap> color.
Anti-aliasing|Interpolate color when grid is not pixel-aligned.

Texture Transform
Truchet|Randomly rotate texture by 90deg to create truchet pattern.
Flip Horizontal|Chance for applying horizontal flip.
Flip VerticalChance for applying vertical flip.
[/proptable]

## Rendering Modes

### Colored Tile

Fill each grid with different color sampled from the <junc tile color/> property.
The <junc gap color/> 
control the color of the gap between tile.

<img-deco grid_colored_tile/>

### Height Map

Render the grid out as height map.

<img-deco grid_height_map/>

### Texture Grid

Fill each grid with the texture from the <junc texture/> property. This mean each cell will contain the 
full surface.

<img-deco grid_texture_grid/>

### Texture Sampler

Fill each cell with solid color sampled from the <junc texture/>.

<img-deco grid_texture_sampler/>

## Truchet Properties

Toggling on the <junc truchet/> when using the <span class="inline-code">Texture Grid</span> mode will rotate 
the sampled texture randomly. Using this effect with a surface with rotational symmetry to create an interesting image.

<img-deco grid_truchet/>

### Flip

The <junc flip horizontal/> and <junc flip vertical/> properties are used to control how often a surface will 
be flip on each axis accordingly.

### Angle

The <junc angle/> property adds random rotation to each surface.
