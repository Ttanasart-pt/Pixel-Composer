Fluffify repeatedly and iteratively draw shapes over content area to create a fluff shape.

## Properties

[proptable]
Fluff
Shape|Shape to draw
Size|Grid size, effects shape density
Radius|Draw size

Iteration
Iteration|Number of iteration
Size Modify|Multiply size with this value for every iteration
Radius Modify|Multiply radius with this value for every iteration
Offset|Offset drawing per iteration

Rendering
Blend Mode|Drawing blend mode.
Substractive|Make the drawing subtract the original surface.
Blend Original|Blend shape with original content.
Fade by Iteration|Make each iteration fafe away the shape.
Invert|Invert output

Decorner
Decorner|Remove corner for smoother result.
[/proptable]
