Generate smoke particle from <node Node_MK_Blast_Flame> flame.

## Properties

[proptable]
Blast
Blast|Original blast object.

Spawning
Amount|Amount of smoke particle to spawn per blast.
Scatter|Add random position.

Spawning > Lifespan
Life Offset|Offset lifespan from the original blast.

Movement
Speed Offset|Offset speed from the original blast.

Direction
Direction Override|Override direction instead of inherit from the original blast.
Direction Offset|Offset direction from the original blast, if using <junc Direction Override> this value will set the smoke direction directly.

Size
Scale Offset|Offset smoke size from the original blast.
Spawn Size|Absolute size.

Spiral
Spiral Use|Draw spiral inside each smoke.

Decay
Decay|Destroy smoke from the middle.
[/proptable]
