Manipulate array of Surface Atlases using affector.

## Properties

[proptable]
Influence
Influence Shape|Shape of the affector.

Position
Mode|Whether to set position directly or adds to original values.

Rotation
Mode|Whether to set rotation directly or adds to original values.
Recalculate Position|Whether to recalculate position value to keep rotation anchor in the middle.

Scale
Mode|Whether to set scale directly or adds to original values or multiply to it.

Interpolate
Target Atlas|Lerp between current atlas to target atlas.
[/proptable]
