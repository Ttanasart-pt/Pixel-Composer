Draw glowing line.

## Properties

[proptable]
Saber
Point 1|Line position.
Point 2|Line position.
Thickness|Line thickness.
Fix Length|Force the <junc Point 2> to keep uniform distance when animating.

Render
Color|Set color gradient over thickness.
Gradient Step|Width of each gradient step.
Glow Intensity|Line glow intensity.

Trace
Trace|Draw line from previous frames for a trail effect.
Trace Texture|Apply texture to the trail.
[/proptable]
