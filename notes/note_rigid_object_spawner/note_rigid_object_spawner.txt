Spawner for creating multiple physics objects. Requires <node Node_Rigid_Object> to define the object properties.

## Properties

[proptable]
Object|Object to spawn.

Spawn
Spawn Area|Area to spawn object.
Spawn Type|Whether to spawn object overtime, or once in burst.
Spawn Delay|Frame delay between each spawning in Stream mode.
Spawn Frame|Spawn time in burst mode.
Spawn Amount|Amount to spawn per frame/ burst.

Color
Random Color|Apply random colro blending over object.
[/proptable]
