Create 3D object by projecting 3 surfaces to each cardinal axis with an optional 3 extra surfaces for the opposite side.

## Properties

[proptable]
Geometry
Extrude Both Side|Whether to extrude both half symmetrically of keep the other part flat.

Noise
Use Noise|Apply random noise to the object.
Threshold|Amount of noise.

Rendering
Voxel Color|Method for setting object color:\nFace Normal: Use surface texture baed on normal.\nFace Average All: Average color from all surfaces.\nFace Average Except:Average color from 2 surfaces and use normal for the rest.
Face Blending|Multiply voxel with color.
Depth Range|Depth range for the Depth Pass output.
[/proptable]
