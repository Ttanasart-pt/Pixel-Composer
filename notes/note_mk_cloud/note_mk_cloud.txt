Generate cloud by scattering shaded circle (puff) in layers.

## Properties

[proptable]
Cloud
Shape|Scatter cloud shape.
Layers|Number of layers.

Transform
Position|Cloud position.
Layer Shift|Shift each layer by a fixed amount.
Size|Cloud size per layer.

Puff
Shape|Puff shape.
Amount|Amount of puff per layer.
Aspect|Height to width ratio.

Subtract
Subtract|Randomly subtract the cloud instead of adding.
Size Padding|Add extra padding when subtract.

Base
Base|Create flat base for the cloud by limiting puff Y position.
Base Spread|Shift puff horizontaly.

Compress
Scale|Scale puff vertically when it got pushed up by the base.
Shift Scale|The amount of scaling.
Shift Stretch|Apply horizontal scale.

Shading
Use Shade|Apply shading to each puff.
Inner Radius|Shadow thickness.
Direction|Shadow direction.

Rendering
Blend Mode|Puff blend mode.
Soft Shade|Use gradient instead of sharp shadow.

Rim
Rim|Add rim light per each layer.
Direction|Rim direction.
Span|Rim radius.

Spiral
Spiral|Add spiral texture inside each puff.
[/proptable]
