Calculate shortest path connecting 2 pixels. Both pixels need to have the same color.

## Properties

[proptable]
Pathfinding
Start|Starting position
End|End position
Diagonal|Allow diagonal line.

Path
Simplify|Remove anchor on a straight line.

Rendering
Draw Mask|Draw original surface.
Draw Path|Draw path.
Range|Path range to draw.
Color|Color over path.
[/proptable]
