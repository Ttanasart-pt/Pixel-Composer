## Interface
- Panel Dialog now support composition.
- Dialog now appear in a separate window (Windows only). Can be disabled in preference.
  - Detached window does not support file dropping and pen pressure.

- [Graph Panel] Node now hide output if requirement failed.
- [Preview Panel] Disable gizmo transformation.
- [Dopesheet] Hide icon now support hold edit.

- New Uniform array node.
